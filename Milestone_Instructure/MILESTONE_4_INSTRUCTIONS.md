## 3. Run Tasks 4.1–4.8, one at a time

**4.1 — Data:** Open `data/raw/customer_reviews.csv` and read `customer_reviews_README.md`. It contains **126 authored synthetic examples** in six themes. They are **not real customer reviews**. Authentic reviews can replace these later with proper permission/licensing.

**4.2–4.5 — Embeddings, KMeans and representative reviews:**

```powershell
.\.venv\Scripts\python.exe -m labs.lab_5_3_clustering --cluster --k 6
```

Look at the three examples nearest each centroid. KMeans produces **numeric IDs**, not human topic names. Read representatives and decide human-readable labels. You can try `--k 4` and compare. The cosine silhouette score is diagnostic, not definitive.

**4.6 — Near-duplicate review detection:**

```powershell
.\.venv\Scripts\python.exe -m labs.lab_5_3_clustering --dedupe --threshold 0.90
```

This compares normalized embeddings with cosine similarity and prints candidate pairs. A high score can be a *related topic* rather than a duplicate: manually inspect false positives and any paraphrases it missed. Try `--threshold 0.85` to explore the trade-off.

**4.7 — Embedding-based zero-shot label matching:**

```powershell
.\.venv\Scripts\python.exe -m labs.lab_5_3_clustering --classify --text "The delivery driver lost my parcel"
```

The script embeds six human-written category descriptions and chooses the closest one. **This is embedding-prototype classification, not a specialized zero-shot NLI classifier**. Similarities are not class probabilities.

**4.8 — Generate and examine the full report:**

```powershell
.\.venv\Scripts\python.exe -m labs.lab_5_3_clustering --all
```

This **overwrites** `docs/lab_5_3_results.md` with real measurements, representative reviews, flagged duplicates, and prototype predictions. Fill the `TODO` lines yourself: label each cluster, inspect coherent/mixed groups, examine duplicate false positives, and discuss misclassifications. Do **not** replace measured observations with invented numbers.

## 6. Common troubleshooting

- `ModuleNotFoundError: No module named 'labs'`: run commands from `E:\semantic-search-engine` using `-m labs.lab_5_3_clustering`, not from the `labs` folder.
- Missing CSV: merge this ZIP's `data/raw` contents into your existing project; keep the old `documents.csv` too.
- First run seems slow: the model is loading and encoding every review on CPU. Later runs still encode unless you add an optional cache.
- Hugging Face download resumes: confirm your previous English model download finished; the model can be read from the shared Hugging Face cache.
- Different KMeans labels across trials: KMeans label numbers are arbitrary; fix `random_state`, but interpret examples rather than relying on cluster numbers.
